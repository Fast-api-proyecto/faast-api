# GameDex

Catálogo web de videojuegos desarrollado en pareja con **FastAPI + SQL (Supabase)** en el backend, desplegado en **Render**, y frontend conectado en **Lovable / Stitch**.

## Enlaces

- **Documentación (`/docs`):** `https://TU-SERVICIO.onrender.com/docs`
- **Frontend publicado:** `https://TU-FRONTEND.lovable.app`

## De qué trata la aplicación
**GameDex** permite gestionar un catálogo de videojuegos guardado en una tabla de Supabase con RLS activado (ver listado, consultar por ID, agregar, editar y borrar videojuegos con título, plataforma, horas, puntuación e imagen).
